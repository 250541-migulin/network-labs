# ЛР-01: Последовательный TCP-сервер с поддержкой докачки

## 📌 Описание
Реализация клиент-серверного приложения на Java с использованием TCP-сокетов.
Поддерживает команды: ECHO, TIME, CLOSE, UPLOAD, DOWNLOAD с возможностью докачки файлов.

## Использование

UPLOAD <файл>       Отправить файл на сервер
DOWNLOAD <файл>     Скачать файл с сервера
ECHO <текст>        Вернуть текст (проверка связи)
TIME                Узнать время на сервере
CLOSE               Закрыть соединение

Для перезаписи необходимо добавить флаг --force

## Демонстрация работы с файлами
download 10kb
download 1mb
upload 100kb
upload 10mb


## Настройки keep-alive на сервере
echo 50 > /proc/sys/net/ipv4/tcp_keepalive_time     - через сколько отправить первый пакет keep-alive после запуска
echo 30 > /proc/sys/net/ipv4/tcp_keepalive_intvl    - интервал после последней команды
echo 3 > /proc/sys/net/ipv4/tcp_keepalive_probes    - неудачных попыток
